# Авторские банки вопросов ЕНТ (2026)

Текстовый формат, чтобы не экранировать LaTeX в JSON. Один файл = один предмет + язык + банк.
Структура: `prisma/ent-banks/<предмет>/<предмет>-<язык>-<NN>.txt`.

```
@subject physics            // slug предмета из seed-ent-banks.ts (SUBJECT_CATALOG)
@bank ent26-physics-ru-01   // sourceBankId (для отката: --remove-bank=ent26-physics-ru-01)
@locales ru                 // ru | kk | kk,ru (одинаковый текст в обоих языках, напр. English)
@topic ru=Механика | kk=Механика | en=Mechanics

? Формулировка (можно в несколько строк, LaTeX в $...$)
P: Необязательный контекстный текст (для заданий «по контексту»)
+ верный вариант            // "+" — верный, "-" — неверный
- неверный
- неверный
- неверный
E: Объяснение решения (обязательно)
D: 3                        // сложность 1–5 (по умолчанию 3)
!fixed                      // не перемешивать варианты (если есть «все верны», «А и Б» и т.п.)
```

Блоки разделяются пустой строкой. Если верных вариантов больше одного — тип `multiple_choice`
(профильные задания 31–40, 2 балла); нужно ≥5 вариантов. Порядок вариантов при импорте
перемешивается детерминированно (иначе верный ответ всегда стоял бы первым).

Проверка без БД: `npx ts-node prisma/seed-ent-banks.ts --check`
Импорт (только добавляет, дубликаты пропускает): `npx ts-node prisma/seed-ent-banks.ts [фильтр-пути]`
